<objective>
Obtain the repository owner's consents, run one containment and format pilot and then the six review passes of round 2 through Devin CLI on the approved text, capture each report verbatim, and record the reports, the consent trail and the mechanically derived findings table in the round-2 review note. The procedure is that of plan 04-03, with the substitutions of this plan; read that plan first.

Tracer (task 1): the whole chain up to the first byte is run (pins, snapshot, pilot inputs, configuration, authentication, flag parsing, what Devin loads, the state of the four servers, the run set) and the consent payloads and questions are composed, writing nothing and sending nothing. Task 2 is the consent checkpoint (the servers, then the run set). Task 3 runs the pilot and then the passes one after another, validating each report file, the output directory and the containment of the repository before the next run. Task 4 assembles the note with the script printers, verifies it against the held report files, runs the stage reported, commits, updates the identity note, and hands the re-enabling of the servers to the orchestrator.

Purpose: roadmap Phase 4 is a hard gate whose first success criterion is that a reviewer that is not the Requestor, and not a fresh context or subagent of it, evaluates the owner-approved diff. The text was fixed and approved again; the same kind of reviewer, under the same rules and the same instructions, reviews it again.

Output: the review note of round 2 in reported form, one sentence of the diff identity note, a summary.

What follows (described, not pre-written): if every pass is usable, plan 04-11 asks the owner to disposition each BLOCKING finding of round 2 (and offers the open information of round 1). If a pass cannot be completed, this plan stops at a checkpoint and the phase stays open; after a format or tool failure the owner decides whether a re-run is made, under a second consent that names the run; after a containment failure no re-run is offered and the owner decides outside the plan.
